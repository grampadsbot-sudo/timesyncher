# Media and stories

- **Saved stories**: Keepsakes Config option (default ON). Not a media toggle.
- Saved Story is a **flag on the Thing** (no separate Story entity). SoTs: `bot-admin/messages/time-syncher/saved-story-flag-on-thing-20260916`, `bot-admin/messages/time-syncher/saved-story-media-in-print-code-20260916`.
- Style one `Ae()` / `fs()` and Style two `Ae(true)` print code **must** embed that Thing’s bound media (`places[].bound_media`, `fo()`, `/ts-thing-media`). Encoded in `src/vacation/trek-style2-bundle.mjs` (`So()` print-origin, `Ba()` url-before-thumbnail, `fo()` bound_media-first). Cursor memory is not a substitute. Placeholders while those URLs 200 = FAIL.
- Detail / print: story/long details on things.
- Bound media chrome: **Edit caption**; **Play video** (live TREK labels).
- Upload/bind: Telegram / `/api/bind-thing-media` (paid add-on). Shared page is not a public self-serve uploader.
- **Not in Config:** no media toggle, no QR toggle. Video QR is a Style-two content rule, not a switch.
- Shared-header **Record voice note** is a travel HTML inject, not Config: `voice-note.md`.
