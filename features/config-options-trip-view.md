# Config Options (Trip View)

Header button `aria-label="Config Options"`. Menu title: **Trip View**.

This is **not** Keepsakes Admin/Config.

| UI label | Key | Default |
| --- | --- | --- |
| Flights | `flights` | ON |
| Hotels | `hotels` | ON |
| Cars | `cars` | ON |

Storage: `thingOverrides.__sectionVisibility`. Off hides that shared tab.
