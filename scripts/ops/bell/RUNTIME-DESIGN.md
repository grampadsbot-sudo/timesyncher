Ruling97/98 host supervisor repair, 2026-10-17.
The bell runner launches Codex at host level. Nested Codex inside a managed worker inherits intentionally protected read-only ~/.codex; it is unsupported and must not be retried. Preserve those protections, auth/config and host identity. Added host runtime write preflight before every GPT dispatch; CODEX_RUNTIME_READ_ONLY exits97 before model start or fallback. Probes create/delete private scratch files in runtime dirs and open state/log files and installation_id write-only without writes. No auth/config read or copy. Workers receive explicit host-only instruction; quota/runtime prerequisites must be performed by the host supervisor, not nested CLI. Normal SSH from the Mac supervisor uses ~/.ssh/id_ed25519_ubuntu and verified host keys; the same command from a nested Ubuntu worker lacks that Mac identity and is not a valid recovery lane. No credential/known_hosts changes. Live host quota and scratch model proof recorded separately; nested write access is not claimed.
